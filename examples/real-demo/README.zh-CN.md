# 真实演示子集

从既有实验中选择 6 个公开抖音账户：两类各两个原标注一致项，加上两个不一致项。名称、简介、标题、网址、封面内容和原始模型分数都是真实数据。每个账户仅包含此前选中的五个候选，不是完整第一页。封面为打包而重新编码成 JPEG，未重新采集或调用模型。

这些样例已明确授权公开。其余团队数据、完整模型请求响应、密钥、登录会话和本机路径不在公开范围。人工标签沿用原实验；可选二次核验 CSV 也只包含所选账户。样例是展示用途，不用于估计全量准确率。

`data/` 遵循版本 1 的数据格式，`results.csv` 保存原始结果。根目录离线分析页面内联相同子集，首次打开无需服务或网络请求即可分析。
